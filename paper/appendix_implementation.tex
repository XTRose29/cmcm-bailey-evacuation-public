\section{Code, Results, and Implementation Details}
\label{app:implementation}

\subsection{Public Repository and Visualization}

The Python model, experiment scripts, result tables, and paper figures are available at
\begin{center}
\url{https://github.com/XTRose29/cmcm-bailey-evacuation-public}.
\end{center}
An interactive visualization is available at
\begin{center}
\url{https://xtrose29.github.io/bailey-evacuation/index.html}.
\end{center}
The webpage shows recorded runs from the final Python model and summaries of the Monte Carlo experiments. Users can select a situation, switch floors, inspect population and queue counts, and change the playback time. Playback speed only changes the animation. The deterministic run shown on the floor plan is separate from the Monte Carlo averages reported below it.

\subsection{Main Code Files}

The model is implemented in \path{model_v2/bailey/}. The main files are:
\begin{itemize}
    \item \path{config.py} and \path{building.py}: model parameters, source notes, building connections, passage capacities, and storage limits.
    \item \path{integer.py}, \path{routing.py}, and \path{flow.py}: whole-person allocation, route choices, walking stages, queues, and population updates.
    \item \path{guidance.py}: the locations and local effects of Crowd Managers.
    \item \path{plugins/randomness.py} and \path{montecarlo.py}: reaction times, random passage service, and separate random streams for each simulation.
    \item \path{manager_search.py} and \path{validation.py}: manager-placement comparisons, implementation checks, and wheelchair travel to outdoor refuge and street level.
\end{itemize}
The formal experiment settings and reporting rules are defined in \path{model_v2/run_overnight.py}.

\subsection{Whole-Person Movement and Randomness}

All populations, queues, and movements are stored as integers. When a group is divided between routes, the deterministic model allocates whole people while carrying the remaining allocation credits to later steps. Random runs use multinomial route choices. Passage service and the available space in the next area limit how many people can move. Fractional probabilities and service credits do not represent fractional people.

For example, the following lines from \path{integer.py} assign a fixed number of people using the largest-remainder rule, after checking that the inputs are valid:
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small,breaklines=true,frame=single]
quotas = total * w / w.sum()
out = np.floor(quotas).astype(np.int64)
order = np.argsort(-(quotas - out).ravel(), kind="stable")
out.flat[order[:total - int(out.sum())]] += 1
\end{lstlisting}

Concert emergencies use lognormal reaction times, normal dismissal uses a truncated Gaussian distribution, and lecture emergencies use a Gamma distribution. The deterministic version uses finite population quantiles. Monte Carlo runs sample individual reaction times and use separate random streams for reactions, movement, and passage service. The legacy class name \texttt{PoissonRandomness} is retained in the code, although baseline passage service uses a binomial distribution with dispersion parameter $0.5$.

The formal experiments use a time step of $0.1$ s and batches of 25 simulations. Each batch seed is generated as
\begin{lstlisting}[language=Python,basicstyle=\ttfamily\small,breaklines=true,frame=single]
block_seed = int(
    np.random.SeedSequence([suite_seed, start])
    .generate_state(1)[0]
)
\end{lstlisting}
The suite seeds are stored in the experiment runner and archived manifest. Keeping the seeds and batch size preserves the prescribed sampling scheme when changing the number of workers. Candidate manager layouts are screened and then evaluated with separate seeds.

Building evacuation is complete only when the number of people inside reaches zero. Reaching a portico counts as leaving the building; assisted wheelchair travel to street level is recorded separately. The formal success criterion is strictly $T<180$ s. Incomplete simulations remain in the analysis, with a restricted time of $\min(T,1800)$ s.

\subsection{Results and Reproduction}

The archived formal results are stored in
\path{results/cluster_formal_20261108/out/}.
The \path{tables/} directory includes individual simulation outcomes, scenario summaries, paired comparisons, sensitivity tests, and numerical checks. The \path{manager_search/} directory contains candidate layouts, screening results, retests, and the selected placement. The manifest records the original parameters, seeds, environment, and source version.

The formal simulations used source version \texttt{9d76e44}. The publication source was taken from \texttt{e4201d3}, which updates cost inputs while retaining the movement model. Revised cost tables are stored separately in \path{results/paper_cost_update/}; the historical cost assumptions remain in the archived manifest. English translations of comments and display labels change file hashes but do not change model calculations. The public release records its own file hashes in \path{release_manifest.json}.

The seven paper figures are in \path{paper/figures/}, with their input tables in \path{paper/source_data/}. They can be regenerated using \path{paper/make_figures.py}. The website source and replay data are in \path{web_v2/}.

After installing the dependencies listed in \path{requirements-paper.txt}, the main deterministic and Monte Carlo experiments can be run from the repository root with:
\begin{lstlisting}[basicstyle=\ttfamily\small,breaklines=true,frame=single]
python model_v2/run_overnight.py 
  --out outputs/reproduction --workers 8 
  --batch-size 25 --stages deterministic,main
\end{lstlisting}
The line breaks above are for presentation; enter the command on one line. Omitting \texttt{--stages} runs the complete experiment plan. The runner uses three wheelchair users within the total population of 1329. The repository README also gives commands for rebuilding figures, checking published data, and opening the visualization without rerunning the experiments.

The original time-step convergence test is retained. Its failure under some deterministic comparisons is an unresolved numerical limitation, so the archived sensitivity results should be considered alongside the main predictions.
